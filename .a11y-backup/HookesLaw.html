胡克定律 / Hooke's Law

F = k · x
形变量 x = F/k = 2.50 m
F: 力 / Force (N)
k: 劲度系数 / Spring Constant (N/m)
x: 形变量 / Extension (m)
拉力 / Force F50 N
劲度系数 / Constant k20 N/m
形变量 Extension (x = F/k) = 2.50 m
演示要点 / Key Points
F
F = k · x
弹簧的伸长量（或压缩量）与施加的力成正比，比例系数为劲度系数k。
k
劲度系数 k
k 越大，弹簧越"硬"，同样的力产生的形变越小。k 越小，弹簧越"软"。
x
弹性限度
胡克定律仅在弹性限度内成立，超过限度弹簧发生永久形变。
