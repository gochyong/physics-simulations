演示要点 / Key points
⊕
主极大条件：d sinθ = nλ（与双缝相同）
Principal maxima same as double-slit: d sinθ = nλ.
N
N 越大，主极大越锐利（半角宽 ∝ 1/N）
More slits → sharper maxima. Width ∝ 1/N. N=2 is the double-slit case.
λ
不同 λ 的主极大角度不同——光栅用于分光
Different λ → different angles. Gratings disperse light into spectra.
