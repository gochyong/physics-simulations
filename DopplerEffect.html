多普勒效应 / Doppler Effect

The change in frequency of a wave when there is relative motion between source and observer.
波源与观察者有相对运动时，观察者感知的波频率发生变化的现象。

f' = 0 Hz
f' : Observed Frequency (观测频率)
f : Source Frequency (波源频率)
v : Wave Speed (波速)
vs : Source Velocity (波源速度)
OBSERVER 观察者 (静止)
运动方向 / Direction
波源速率 vs / Source Speed100 m/s
>
波速 v / Wave Speed340 m/s
>
波源频率 f / Source Frequency10 Hz
>
频率对比 / Frequency Analysis
波源频率 f (Source)10 Hz
观测频率 f' (Observed)12.5 Hz
提示： 当波源向观察者靠近时，波阵面被压缩，观测频率 升高；远离时波阵面被拉伸，频率 降低。
