放射性衰变 / Radioactive Decay

剩余核数 N = 1000 半衰期 T½ = 5.0 s 时间 t = 0.0 s
初始核数 N₀1000
半衰期 T½5.0 s
演示要点 / Key Points
N
N = N₀·e^(−λt)
指数衰变律，λ=ln2/T½为衰变常数。
½
半衰期 T½ = ln2/λ
每过一个半衰期，核数减少一半。与初始数量无关。
📊
随机性 vs 统计规律
单个核衰变是随机的，大量核整体遵循指数衰变规律。
∞
14C定年应用
利用14C半衰期5730年测定考古样品年代。
