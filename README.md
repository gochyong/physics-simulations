## 📚 项目简介

涵盖 6 大板块、50 个交互式物理模拟：

| 板块 | 数量 | 内容 |
|------|------|------|
| ⚙️ 力学 | 21 | 密度→压强→浮力→力的合成→牛顿定律→斜面→抛体→圆周→简谐→动量→功→能量→力矩 |
| 🔥 热学 | 4 | 热传导→比热容→理想气体→热力学第一定律 |
| ⚡ 电磁学 | 8 | 电阻→欧姆定律→串并联→电容→库仑定律→安培力→洛伦兹力→电磁感应 |
| 🌊 波 | 10 | 波形→横纵波→波速→叠加→驻波→多普勒→偏振→单缝衍射→双缝干涉→光栅 |
| ⚛️ 近代物理 | 4 | 光电效应→卢瑟福散射→质能方程→放射性衰变 |
| 🌌 天文 | 3 | 万有引力→开普勒定律→月相变化 |

## 🚀 使用方式

- **在线**: 访问 GitHub Pages
- **本地**: 下载后双击任意 `.html` 文件用浏览器打开
- 纯静态 HTML，无需安装任何依赖

## 🛠️ 技术栈

HTML5 Canvas + 原生 JavaScript，无框架、无构建工具、零依赖。
